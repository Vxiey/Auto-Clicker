# Auto Clicker

High-precision Windows auto clicker, key remapper, and macro engine.

## Status

Early development. The first milestone is a native Rust core with:

- high-precision absolute-deadline scheduling
- Windows `SendInput` injection
- global hotkeys
- click and keyboard automation
- macro recording/playback foundation
- key and mouse remapping foundation
- benchmark telemetry for actual CPS and jitter

The project is being implemented clean-room. External open-source autoclickers and macro tools are used only as references unless their licenses explicitly permit reuse.
