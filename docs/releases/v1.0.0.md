# VxClick 1.0.0

VxClick 1.0.0 is the first complete release of the Windows automation stack.

## Highlights

- Precision auto clicker with CPS and interval control
- Randomization, burst mode, fixed position and multi-point targeting
- Global native hotkeys with toggle, hold and emergency stop
- Macro Studio with native global recording, persistent macros and QPC playback
- Key and mouse remapping with per-process scope and consume/pass-through behavior
- Sandboxed Lua automation compiled into native macro events
- Profiles with foreground-process auto switching
- Diagnostics, crash logs and precision benchmarks
- GitHub updater and Windows release bundles

## Windows artifacts

The release workflow builds a portable `VxClick.exe` and Windows installer bundles. Prefer the installer for normal use and the portable executable for testing or portable setups.
