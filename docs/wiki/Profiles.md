# Profiles

Profiles keep automation settings separate for different applications and games.

A profile can store clicker CPS, mouse button, click mode, randomization, burst behavior, start hotkey, emergency-stop hotkey and process matching.

## Process auto-switch

When enabled, VxClick checks the foreground process and automatically activates the matching profile. The native hotkey runtime then refreshes the bindings and clicker settings without requiring a restart.

Keep a safe Default profile for desktop use and create dedicated profiles for applications with different hotkeys or timing requirements.
