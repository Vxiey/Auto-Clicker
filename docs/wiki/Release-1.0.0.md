# VxClick 1.0.0

VxClick 1.0.0 is the first complete Windows release of the precision automation stack.

## Included

- Precision auto clicker with CPS/interval control
- Randomization, burst, fixed-position and multi-point modes
- Global native hotkeys with toggle, hold, once and Emergency Stop
- Macro Studio with persistent native recording and QPC playback
- Native key/mouse/chord remapping with process scopes
- Sandboxed Lua validate/run workflow
- Foreground-process profile auto switching
- Diagnostics and precision benchmark telemetry
- GitHub updater and Windows release bundles

## Download

Use the GitHub Release assets. The release contains a portable `VxClick.exe` plus Tauri Windows installer bundles.

## Safety

Use at your own risk. VxClick does not provide anti-cheat bypass or anti-detection functionality.
